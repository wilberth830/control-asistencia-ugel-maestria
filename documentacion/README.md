# Documentacion CHIQUISTRUKIS

Indice principal de documentacion funcional, tecnica y de revision del proyecto.

Esta carpeta concentra documentos de consulta para lectura, revision y
exposicion.

## Secciones

| Seccion | Contenido |
|---------|-----------|
| [Auditorias](auditorias/README.md) | Auditorias tecnicas generadas y reglas para nuevas auditorias |
| [Normas](normas/README.md) | Estandares de codificacion y convenciones del proyecto |
| [Post](post/README.md) | Documentos explicativos para exposicion, costos y notas de apoyo |

## Lectura sugerida

1. Revisar [Normas de codificacion](normas/coding_standards.md).
2. Revisar [Reglas de auditoria](auditorias/reglas_auditoria.md).
3. Consultar [Auditoria completa historica](auditorias/auditoria_completa.md).
4. Consultar [Precios IA](post/precios_ia.md) si se explica el uso de IA.

## Regla de mantenimiento

Cuando se agregue un nuevo documento dentro de `documentacion/`, debe tener:

- Un enlace de regreso al indice de su seccion.
- Un nombre claro en minusculas y con guion bajo.
- Texto en espanol.
- Codigo, rutas, endpoints y tablas en ingles cuando corresponda.
