# Skill: UI admin y flujos UX

## Pantallas

login, dashboard, personal, carga (wizard), asistencia (Anexo 03 + panel),
justificaciones, reportes

## Patrones

- Filtros compactos (btn-sm) junto a mes/año.
- Asistencia: ~90% grilla + ~10% panel (fecha, estado, justificación).
- Reportes: filtro vertical; preview; export; enlace a Asistencia.
- Dashboard: archivos, empleados, gráfico marcaciones, últimas cargas.

## Evitar

Botones de filtro a ancho completo; corregir datos solo desde Reportes;
wizard que guarde en silencio sin lista verde/rojo.
